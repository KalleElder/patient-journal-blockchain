## Gemensamma beslut

- Medicinsk journaldata ska endast lagras i SQL-databasen och aldrig i blockchain.
- Blockchain ska endast innehålla metadata om åtkomst och handlingar.
- Projektet delas upp i frontend, backend/SQL, blockchain/P2P och integration/dokumentation.
- Roller som används är `DOCTOR`, `NURSE`, `CARE_CENTER`, `PATIENT` och `UNAUTHORIZED`.
- Journalanteckningar planeras använda `PRIVATE`, `STAFF` och `ALL` för synlighet.
- Gruppen använder feature branches och Pull Requests.
- Ingen ska arbeta direkt på `main`.
- En annan gruppmedlem ska genomföra code review innan merge.
- Små och tydliga Pull Requests föredras.
- Commit-meddelanden skrivs på svenska.
- Första gemensamma målet är ett fungerande flöde:
  login → journal → SQL → audit log → blockchain.
- Grundfunktionerna prioriteras före mer avancerade delar som P2P, digital signering, Merkle Tree och fork-hantering.
